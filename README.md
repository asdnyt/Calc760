# حاسبة CT-760 (Android / Kotlin / Compose)

## البناء
- Android Studio: افتح المجلد ثم Build > Build APK.
- GitHub Actions: ارفع المشروع إلى مستودع، سيُبنى الـAPK تلقائياً (Artifacts > calc760-apk).

## المفاتيح
- ON/AC: تشغيل/مسح الكل | CE: مسح الإدخال | CORRECT: حذف رقم (أو تصحيح خطوة أثناء CHECK)
- CHECK ◀ ▶: تصفّح الخطوات (حتى 112) | AUTO REPLAY: تكرار آخر عملية
- GT: المجموع الكبير (ضغطتان تمسحه) | M+ M- MRC: الذاكرة (MRC مرتين تمسحها)
- MU: Mark-Up: A×B MU = A(1+B%) ، A÷B MU = A/(1−B%) ، A−B MU = A(1−B%)
- 00، √، %، +/−، OFF
